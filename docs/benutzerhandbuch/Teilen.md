# Planungsansicht teilen

Mit dem **Teilen-Button** (Share-Icon oben rechts) kannst du deine aktuelle Stundenplanansicht
als Link weitergeben oder als PDF exportieren.

## Link teilen

1. Klicke oben rechts auf das **Teilen-Symbol**.
2. Es öffnet sich der Dialog **„Planungsansicht teilen"**.
3. Der generierte Link ist bereits im Textfeld sichtbar –
   klicke auf das **Kopier-Symbol** rechts daneben, um ihn in die Zwischenablage zu kopieren.
4. Teile den Link z. B. per E-Mail, Chat oder Browser-Lesezeichen.

> **Hinweis:** Der Link enthält alle aktuell gewählten Studiengänge, Tabs und Einstellungen,

## Als PDF exportieren

Im selben Dialog findest du unten den Button **„Als PDF exportieren"**.
Ein Klick erzeugt eine druckbare PDF-Version deiner aktuellen Ansicht.

## Temporäre Ansicht übernehmen

Wenn du einen geteilten Link öffnest, wird die Ansicht zunächst als **temporäre Ansicht**
geladen (gelber Hinweis oben links).

- Klicke auf **„Übernehmen"**, um die Ansicht dauerhaft zu speichern.
- Klicke auf **„Zurückspringen"**, um zur vorherigen Ansicht zurückzukehren.

Für genauere Informationen siehe [Temporäre Ansichten](TemporäreAnsicht.md).
